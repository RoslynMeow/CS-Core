\chapter{Algorithm Definition and Asymptotic Analysis}

本章建立评价算法的统一度量，按数学四段体：对象--不变式--定理--实例化。算法本体为基本操作上的有限序列，伪代码为数学记号，高级语言为语义实现。

\section{算法的定义与四大核心特征}

\begin{itemize}
    \item \textbf{对象}：算法为基本操作集 $\mathcal{P}$ 上的有限序列 $A=\langle op_1,\dots,op_k\rangle$，配备控制构造子（顺序、分支、循环）。
    \item \textbf{规约 (Specification)}：前置 $Pre$ 与后置 $Post$ 的谓词变换 $ \{Pre\} A \{Post\}$。
    \item \textbf{四大特征}：
    \begin{enumerate}
        \item \textbf{有穷性}：$\exists B$ 使执行步数 $\le B$；每步有穷时间内完成。
        \item \textbf{确定性}：$\forall$ 状态，下一步唯一。
        \item \textbf{可行性}：每 $op_i\in\mathcal{P}$ 可实现。
        \item \textbf{输入/输出}：$I\in\mathcal{D}_{in}^*$, $O\in\mathcal{D}_{out}^+$，满足 $Post(I,O)$。
    \end{enumerate}
    \item \textbf{实例化}：同一算法可细化为伪代码（数学记号）或 C/Python 程序（语言实现），正确性由规约保持。
\end{itemize}

\section{算法的描述层级}

\begin{itemize}
    \item \textbf{规约层}：用谓词逻辑描述 $Pre/Post$。
    \item \textbf{细化层}：用伪代码与控制算子表达，与语言无关的数学记号（本书采用）。
    \item \textbf{实现层}：高级语言对细化的语义实现（如 C/Java/Python 的编译/解释），编译器保持语义等价。
    \item \textbf{定理}：伪代码到语言实现的翻译保持 $Pre/Post$，仅时空常数因子变化。
\end{itemize}

\section{算法的时间复杂度 (Time Complexity)}

评价标准为输入规模 $n$ 与资源消耗的渐进趋势，非绝对计时。

\subsection{渐进记号定义}

\begin{itemize}
    \item \textbf{大 O（上界）}：$\exists c>0,n_0>0$ 使 $\forall n\ge n_0, T(n)\le c\cdot f(n)$，记 $T(n)=O(f(n))$。
    \item \textbf{$\Omega$（下界）}：$\exists c>0,n_0$ 使 $T(n)\ge c\cdot f(n)$。
    \item \textbf{$\Theta$（紧界）}：$T(n)=O(f(n))\land T(n)=\Omega(f(n))$。
    \item \textbf{实例化}：忽略低阶与常数，聚焦 $n\to\infty$ 趋势。
\end{itemize}

\subsection{复杂度组合原理}

\begin{itemize}
    \item \textbf{串联}：$O(a)+O(b)=O(\max(a,b))$。
    \item \textbf{嵌套}：$O(a)\cdot O(b)=O(a\cdot b)$。
    \item \textbf{实例化}：循环嵌套为乘法，顺序为取极大。
\end{itemize}

\subsection{\texorpdfstring{$O(\log n)$}{O(log n)} 递归栈}

递归深度 $H$ 的调用栈辅助空间为 $O(H)$，平衡分治时 $H=O(\log n)$（如快排期望）。

\subsection{\texorpdfstring{$O(n)$}{O(n)} 线性辅助（Clone）}

需与输入等大副本 $A'$ 时辅助 $O(n)$（如归并、哈希表）。
