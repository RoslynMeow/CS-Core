{\bfseries 摘要}
\end{center}

\vspace{1em}

\begin{center}
本教程采用自顶向下的视角系统讲解计算机网络：从应用层协议出发，逐层深入到运输层、网络层（数据平面与控制平面）、链路层，并覆盖无线与移动网络以及网络安全。教程强调「分层 + 协议 + 性能」三条主线，用可计算的公式与可交互的例子说明时延、吞吐、可靠传输、拥塞控制、路由与转发、差错检测、密钥交换等核心机制，帮助读者建立贯穿五层模型的完整心智模型。
\end{center}
